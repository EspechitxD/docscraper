# Fase 10 — plano de execução

A arquitetura permanece: Electron, React, FastAPI, SQLite, Playwright e os exportadores atuais.

1. Representação canônica refeita a partir das regiões vivas, com histórico em tabela nova e migração aditiva.
2. Contrato único de tradução, seleção por ID e glossário do projeto na interface.
3. Empacotamento do backend e regra de não usar o virtualenv quando o app estiver instalado. Validação Windows fica pendente.
4. Overlay injetado no HTML do navegador, com medição geométrica.
5. Painel de imagens sobre a API existente, mais exclusão e exportação.
6. Classificador de título ajustado e medido num conjunto próprio.
7. Estado do Argos sem instalação silenciosa. Equação OMML apenas no caso já considerado confiável.

Cada etapa termina com teste executado. O relatório final lista só resultados obtidos nesta máquina.
